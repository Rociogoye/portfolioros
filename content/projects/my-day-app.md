## El proyecto

**My Day App** es una aplicación web publicada para organizar el día de forma flexible, registrar avances y revisar cómo se distribuye la energía entre tareas, entrenamiento, estudio y vida personal.

La propuesta prioriza una experiencia amable: permite avanzar por pasos pequeños, cambiar entre vista diaria, planificación, registro y revisión, y conservar los datos localmente en el navegador.

## Mi rol

- Definir la propuesta y la arquitectura de la aplicación.
- Diseñar los flujos principales de planificación, registro y revisión.
- Implementar la interfaz responsive con HTML, CSS y JavaScript.
- Incorporar estados, filtros, métricas, modo oscuro y persistencia local.
- Publicar la aplicación y mantener el código en GitHub.

## Funcionalidades principales

- Vista de tareas del día y prioridades.
- Planificación por fechas y bloques de tiempo.
- Registro de hábitos, energía y notas.
- Revisión visual del progreso.
- Etiquetas para organizar distintos ámbitos de la vida.
- Modo claro y oscuro.
- Persistencia local sin registro obligatorio.

## Decisiones de UX

- Reducir la carga cognitiva con cuatro vistas claras: Hoy, Planificar, Registrar y Revisar.
- Convertir objetivos grandes en pasos concretos y manejables.
- Usar una jerarquía visual suave para que la aplicación no se sienta como otra fuente de presión.
- Mantener la aplicación ligera y accesible desde cualquier dispositivo.

## Tecnologías

HTML semántico, CSS, JavaScript, Tailwind CSS y almacenamiento local del navegador.
